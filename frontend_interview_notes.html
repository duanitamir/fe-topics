General tech

Study in order to build the mental models, or search for a specific concept. Each page moves from foundations to application, tradeoffs, and interview review.

Preparing for architecture interviews? Open the separate System Design track, starting with a worked chat-app case study.

Language foundations

Understand runtime behavior, asynchronous work, and type contracts.

  1. JavaScript Language Mechanics

    Scope, closures, this, prototypes, immutable updates, equality, and memory retention.

  2. Promises & Async Programming

    Promise behavior, combinators, concurrency, cancellation, async iteration, and backpressure.

  3. TypeScript

    Runtime boundaries, structural typing, unions, generics, satisfies, and utility types.

Browser foundations

Understand how the browser schedules work and delivers interactions.

  1. HTTP & Networking

    Request lifecycle, methods/status codes, caching, validators, transport costs, and browser boundaries.

  2. DOM Events & Scheduling

    Execution order, event flow, cancellation, listener lifetime, and Shadow DOM.

  3. Browser APIs

    Choose APIs for cancellation, observation, background computation, persistence, and cross-tab coordination. Define the lifecycle, failure behavior, and data owner before using each mechanism.

  4. Accessibility Foundations

    Accessibility tree, names, ARIA, keyboard/focus models, live regions, and practical WCAG verification.

React application design

Move from rendering mechanics to reusable components and explicit state ownership.

  1. React Rendering

    Start with how React computes and commits updates, preserves identity, and schedules work. Then follow initial HTML delivery, hydration, Server Components, and streaming.

  2. React Hooks

    State, refs, synchronization, identity, subscriptions, async UI, and custom hooks.

  3. Component Composition

    Start with composition and state ownership, then define customization, accessibility guarantees, and form validation and submission contracts.

  4. State Ownership & Context

    Choose the authoritative owner first, including the URL. Model transitions and sharing, then coordinate remote data, drafts, overlapping mutations, and real-time updates.

  5. Application Design Patterns

    Strategy, adapters, dependency injection, facades, ports, BFFs, incremental migrations, and failure containment.

  6. Routing & Navigation

    Navigation models, history, nested routes, data loading, focus, scroll restoration, and unsaved changes.

API implementation

Build explicit endpoint contracts and choose the right client-facing API model.

  1. Node.js Runtime & Server Execution

    libuv, worker threads, streams, backpressure, graceful shutdown, and request context.

  2. Backend & API Fundamentals

    Request pipelines, validation, errors, pagination, indexes, transactions, pools, and N+1 queries.

  3. GraphQL

    Schema, operations, execution, resolvers, N+1, nullability, caching, security, and REST comparisons.

Production quality

Measure performance and protect application boundaries.

  1. Build Tooling & Modules

    ESM/CommonJS, resolution, bundling, transpilation, polyfills, tree shaking, assets, and configuration.

  2. Frontend Performance

    Measure user impact, understand rendering costs, diagnose bottlenecks, and optimize.

  3. Web Security & Authentication

    Establish identity and resource permissions, manage sessions and credentials, then examine browser vulnerabilities and API defenses.
